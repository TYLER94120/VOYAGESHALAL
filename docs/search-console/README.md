# Search Console — relevé 3 mois, voyageshalal.fr (17 octobre 2026)

Ces fichiers sont des **transcriptions manuelles** des captures d'écran de l'export Search Console du 17/10, lignes visibles uniquement. Ils ne remplacent pas les exports CSV originaux : dès qu'un export brut est disponible, il remplace ces fichiers.

- `pages.csv` : pages les plus populaires (clics, impressions, CTR, position).
- `requetes.csv` : requêtes les plus fréquentes (lignes visibles).
- `jours.csv` : clics, impressions, CTR et position par jour, du 15/07 au 27/09 (la capture s'arrête là).
- `appareils.csv` : mobile, ordinateur, tablette.
- `pays.csv` : France et principaux pays.
